# Job Copilot

**Full-Stack Product Engineering · Job Intelligence · ATS Ingestion · Resume Matching · Application Workflows**

Job Copilot is a career workflow platform designed around job discovery, candidate intelligence, resume-to-job analysis, application tracking, and AI-assisted preparation.

This repository is a curated, recruiter-safe engineering showcase. The complete private product implementation is maintained separately.
